# 🎀 Rehan - My Notes
[![Netlify Status](https://api.netlify.com/api/v1/badges/f3b937f4-14bc-46d5-9c24-f2ea5fbe201e/deploy-status)](https://app.netlify.com/projects/thriving-choux-b7e1e6/deploys)

A beautifully designed personal planning and note-taking web application.

![Mino UI Preview](canvas.png)

## Features

- 📅 **Planning Days** - Organize your days with visual planning cards
- 📝 **My Notes** - Create and manage sticky notes with timestamps
- 🎨 **Color-Coded** - Notes and folders color-coded for easy organization (yellow, pink, blue)
- 🔍 **Search** - Quick search functionality
- 🎉 **Birthday Announcement** - Special animated greeting banner

## Tech Stack

- **HTML5** - Semantic markup
- **Tailwind CSS** - Styling (via CDN)
- **Lucide Icons** - Icon library (via CDN)
- **Google Fonts** - Inter font family

## Getting Started

Open `index.html` in your web browser. No installation or server required.

```bash
# Just open the file directly
open index.html
```

## Design

- Clean, modern UI with rounded corners and soft shadows
- Responsive layout that adapts to different screen sizes
- Subtle hover animations and transitions
- Professional color palette with accent colors
