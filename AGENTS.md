# AGENTS.md

This is a simple static HTML project - no build system, tests, or complex tooling.

## Project Structure

- `princess plan.html` - Main application (single HTML file with embedded CSS/JS)
- `canvas.png` - Image asset used in the UI

## Tech Stack

- Tailwind CSS (via CDN)
- Lucide Icons (via CDN)
- Inter font (Google Fonts)

## Running the Project

Open `princess plan.html` directly in a browser - no server or build step required.
